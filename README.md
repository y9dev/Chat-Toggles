# Chat Toggles

A mod that lets you quickly switch between different chat modes using control keybind and 1-9.

## Features

* See a preview of the message directly in chat before sending it
* Configure everything through Mod Menu
* Support for up to 9 modes for now
* More than 9 modes are planned for future versions

## Configuration

All mod settings can be changed through the Mod Menu configuration.

## Controls

`Control + 1-9` — switch between chat modes, control keybind must be configed on settings

The selected mode is applied to your message and shown in the chat preview before you send it.
